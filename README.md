# 🏎️ Formula 1 Image Gallery

## Overview

This project is a responsive Formula 1 image gallery created using HTML and CSS. It showcases Formula 1 racing images in a visually appealing grid layout with a modern racing-inspired design.

The gallery uses CSS Grid for layout management and includes hover effects, custom fonts, and responsive behavior for different screen sizes.

---

## Features

✅ Responsive Design

✅ 3-Column Layout on Desktop

✅ 1-Column Layout on Mobile

✅ CSS Grid Layout

✅ Hover Zoom Effects

✅ Racing-Themed UI

✅ Custom Google Font (Orbitron)

✅ Modern Red & Black Color Scheme

---

## Technologies Used

- HTML5

- CSS Grid

## How to Run

1. Download or clone the repository.
2. Ensure all image files are in the project folder.
3. Open `index.html` in your browser.

---

## Responsive Layout

### Desktop View
- Displays images in 3 columns.

### Mobile View
- Automatically switches to a single-column layout.
